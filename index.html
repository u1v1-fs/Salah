Step-by-step guidance to synchronize the system clock on Android TV, Google TV, or Amazon Fire Stick:
  1. On your remote, press Home and open TV Settings (Gear icon ⚙️).
  2. Scroll to Device Preferences or System > Date & Time.
  3. Toggle Automatic date & time to Use network-provided time.
  4. Check Time zone: Ensure it is set to the correct local zone (e.g., Asia/Kolkata, Europe/London, America/New_York).
  5. If using Wi-Fi that requires captive portal login, connect to Wi-Fi first so Android TV can reach Google NTP servers.
Step-by-step guidance for Windows Mini PCs, Intel NUCs, or kiosk computers:
  1. Press Win + I to open Windows Settings.
  2. Select Time & Language > Date & Time.
  3. Turn ON Set time automatically and Set time zone automatically.
  4. Under Additional settings, click the Sync now button.
  5. If time continues to drift after power cycling, replace the CR2032 coin cell battery on the motherboard.
Guidance for Raspberry Pi displays and Linux kiosk distributions:
  1. Open a terminal or SSH session to the kiosk device.
  2. Enable automatic network time synchronization: sudo timedatectl set-ntp true
  3. Restart the timesyncd service: sudo systemctl restart systemd-timesyncd
  4. Verify status: timedatectl status (Look for NTP service: active and System clock synchronized: yes).
  5. For offline Pis, install a hardware DS3231 I2C Real-Time Clock module so time persists through power outages.
